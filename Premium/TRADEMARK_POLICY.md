# Trademark Policy (Community Release)

The code in this repository is open-source (AGPL-3.0-or-later), but project branding remains controlled.

## You may
- Fork and modify the source code under the repository license.
- Redistribute modified builds with clear attribution and license compliance.

## You may not
- Use "Digital Global Village" or "USFM Integrity Studio" branding in a way that implies endorsement.
- Reuse logos, product identity, or company marks without written permission.
- Publish confusingly similar official-looking releases under the same brand identity.

## Required when redistributing
- Keep copyright and license notices.
- Clearly identify your fork/project name if modified.
- Document material changes from upstream.
