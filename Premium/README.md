# Premium application

This directory contains the Avalonia application for the isolated USFM
Integrity Studio Premium redesign.

![Digital Global Village Logo](Assets/dgv-logo.png)

Build and run from the repository root:

```bash
dotnet restore Premium/UsfmIntegrityStudio.csproj
AVALONIA_TELEMETRY_OPTOUT=1 dotnet run --project Premium/UsfmIntegrityStudio.csproj
```

See the repository-level `README.md` for features, verification commands,
safety behavior, optional source comparison, licensing, and trademark terms.
