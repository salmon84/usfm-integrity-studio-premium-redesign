# Privacy policy

## Summary

USFM Integrity Studio Premium Redesign processes selected files locally. The
application does not contain analytics, advertising, crash-report uploads,
machine identifiers, account login, cloud synchronization, or an automatic
update checker.

## Network activity

The processing engine does not make network requests. The application opens an
external browser only when a user deliberately selects a website or source-code
link. The destination website and browser then operate under their own privacy
terms.

## Local data

The application reads only files and folders selected by the user or required
for the selected operation. Generated reports, standardized DOCX copies, USFM
files, recovery copies, and BTTW project packages are written to user-selected
or clearly reported local locations.

The optional `UIS_SOURCE_TEXT_ROOT` environment variable points to a local
source-text directory for context-aware comparison. Its value and source text
are not transmitted by the application.

## Operating-system and third-party behavior

Files stored in OneDrive, iCloud, Dropbox, network shares, backups, antivirus
systems, or other synchronized locations may be processed by those external
services. That behavior is outside this application's control.

## Security reports

Do not include unpublished scripture, project archives, credentials, personal
paths, or translator information in public issues. Use GitHub private
vulnerability reporting for sensitive security findings.

## Future changes

Any future telemetry or network service must be opt-in, documented here before
release, disabled by default, and must never collect scripture content or local
project paths. The current application has no such telemetry.
